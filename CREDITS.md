## Refreshing data

To adapt the city theme and helper scripts for your own account, see the
[profile refresh setup guide](docs/REUSE_PROFILE.md), including reuse terms.

Use **Actions → Refresh profile artwork → Run workflow** to regenerate the
statistics, language chart and contribution animation. It runs only when
requested, with no scheduled jobs and no personal access token secrets.
All assets are committed locally to this repository. A failed service response
stops the workflow before publishing, leaving the previous artwork intact.

The 3D calendar refreshes automatically every day at 09:17 in `Australia/Sydney`,
including daylight saving time changes. GitHub may delay scheduled runs.
Use **Actions → Refresh contribution city → Run workflow** for an immediate refresh.
It uses the repository's built-in `GITHUB_TOKEN`; no personal token or extra
account permission is required.

Both refresh jobs check out the current default branch when they start, so a
queued job includes changes published by the preceding refresh.

The **Total Stars** badge is original SVG artwork generated by
`scripts/refresh-stars.py`. It sums GitHub's `stargazers_count` across all public
repositories owned by this account, including archived repositories and forks;
it does not count repositories owned by other accounts or organizations.
The script reads every page of results and keeps the previous badge if fetching
or validation fails. The daily contribution-city workflow refreshes it at 09:17
in `Australia/Sydney`, and either refresh workflow can update it on demand.
It uses GitHub's API directly and needs no third-party statistics service or
personal token secret.

The earned-achievements showcase links to native badges already visible on this
account's public GitHub profile. `scripts/refresh-achievements.py` reads GitHub's
native achievement hovercards, removes duplicate sidebar entries, and updates
only the marked README block. It neither grants achievements nor displays
unearned badges. The badge images are served by GitHub and remain GitHub's
artwork; they are not relicensed by this repository. Both refresh workflows
update the showcase, and a failed or changed profile response preserves the
previous version.
